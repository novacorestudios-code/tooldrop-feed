# ToolDrop Public Feed

Automated RSS collector and static GitHub Pages host for **ToolDrop: Power Tool Deals** (`com.tooldrop.deals`).

- `public/deals_feed.json` — Normalized US power-tool deal feed refreshed every 30 minutes via GitHub Actions.
- `public/privacy.html` — Privacy Policy for Google Play Console.
- `public/app-ads.txt` — AdMob authorized seller record.
